# Official public starter sources

These are downloaded source snapshots, not generated legal text. The manifest records original URLs and SHA256 hashes. The app checks the hashes before import. Preserve provenance and acknowledge the issuing institutions when sharing excerpts.

* Indian Contract Act, 1872: India Code, https://www.indiacode.nic.in/bitstream/123456789/2187/2/A187209.pdf
* Sumit v. State of U P & Anr., 2026 INSC 145: Supreme Court of India, https://api.sci.gov.in/supremecourt/2026/3119/3119_2026_5_32_68496_Judgement_09-Feb-2026.pdf

Retrieved 8 October 2026. Neither snapshot is certified current, complete or applicable to a particular matter. Reuse is subject to the source institutions' applicable terms. This starter set is intentionally small; it is not a comprehensive Indian legal database. Private case documents belong in an authenticated tenant workspace.

Use **Case Law & Documents → Load official starter sources**. Sources are parsed and indexed normally; the original PDFs remain available through source inspection. The button skips already-ready identical sources.
